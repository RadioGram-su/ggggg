# Гром — музыкальный плеер для Android

Собирается автоматически GitHub Actions при пуше в ветку `player`; готовый APK кладётся в ветку `player-out` (`Grom.apk`).

Сборка вручную: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

Шрифты Unbounded, Onest, Martian Mono — под лицензией SIL OFL 1.1 (ci/OFL-fonts.txt).
